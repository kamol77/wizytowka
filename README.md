# Wizytówka usługowa (Astro + Tailwind v4)

    npm install
    npm run dev      # podgląd
    npm run build    # gotowe pliki w /dist (Netlify / Vercel / Cloudflare Pages)

Nowy klient: edytuj tylko `src/config/site.ts` (zmień `PRESET`, dane, zdjęcia z `/public/images`).
Nowy preset: dopisz wpis w `src/config/presets.ts`.
